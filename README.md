# Splunk-Dashboard

Create a splunk Dashboard which reflects Ratings Business TODAY having different tiles each explaining the metrics for
1. Number of New Issue/New Issuer jobs created today
2. Number of Review Jobs created today
3. Number of Annual Review Jobs created today
4. Number of Issuers Notified today
5. Number of Committess concluded today
6. Number of jobs for which ratings are Added to CORE today
7. Number of jobs for which ratings are Released to CORE today
8. Number of PCRs published today
